### What's new - Sites

## What Changed
RWS updated the Tridion Sites 10.1 product page with structural/rendering changes — the visible content descriptions for new features are no longer exposed in the accessibility tree, and the cookie consent UI was refactored.

## Notable Updates
- **Feature detail text removed from DOM**: Descriptions for "Granular BluePrinting," "BluePrinting management features," and "Contextual views for translators" are no longer present as `StaticText` nodes — content may now be lazy-loaded or rendered differently (e.g., behind a click/expand interaction)
- **Video player changed**: The `<Video>` element was removed from the video player section; playback may now rely on a custom embed rather than a native video element
- **Cookie consent UI restructured**: The cookie banner changed from a `dialog` element to a plain `generic` container, and the "Reject All" / "Accept All" buttons moved to a sibling element — functionally the same but a structural refactor
- **"Discover more" card descriptions hidden**: Supporting text for the three promo cards ("Seven reasons to adopt Tridion Sites 10," "See Tridion Sites in action," "Content management blog") was removed from the accessibility tree
- **Footer separator characters removed**: The `|` pipe characters between legal links in the footer were stripped out

### What's new - Docs

## What Changed
The Tridion Docs "What's New in Tridion Docs 15" page was updated, with several sections losing their descriptive body text — content that previously explained features is now stripped out, leaving only headings and images.

## Notable Updates
- **Draft Companion**: Removed the explanatory text about the two ways authors can engage with Draft Companion, and removed the closing paragraph about authors remaining in full control of AI suggestions.
- **Content variables in Draft Space**: Body text explaining that authors can now insert variables directly in Draft Space without a third-party XML editor was removed.
- **Organize Space**: Descriptive paragraphs explaining it as the successor to Content Manager Web Client, its browser support, and mobile optimization were removed.
- **Publication Hub**: Three explanatory paragraphs about the hub's role, task management, and Jira/Workfront API integration were removed.
- **Metrics and ROI**: Text describing the reporting feature and content reuse ROI metrics was removed.
- **Publication Manager / Settings menu**: Descriptive text about UI/UX updates and centralized settings management was removed.
- **Translation job wizard steps**: All four step descriptions (title/description, object types, language groups, confirmation) were removed.
- **Modernized security / Extended platform support**: Body text for both sections was removed.
- **Cookie Notice UI**: Restructured — the dialog wrapper changed and the "Reject All" / "Accept All" buttons moved outside the inner dialog structure.
- All other changes are internal reference number renumbering with no functional or content significance.
