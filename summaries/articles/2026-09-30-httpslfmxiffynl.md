# RSS Feeds for Last.fm

Source: https://lfm.xiffy.nl/

## Summary
This page provides a tool for generating RSS feeds from Last.fm user data. Users enter their Last.fm username to get feed URLs for various listening statistics. The service has been updated over the years to include image support and recommended tracks in multiple formats.

## Key takeaways
- Supports RSS feeds for recent tracks, loved tracks, top tracks, and top artists
- Top tracks/artists feeds accept a time period parameter: 7day, 1month, 3month, 6month, 12month, or overall
- Added image support — when Last.fm provides a non-default image, its large version is included as an enclosure
- Recommended tracks were added in 2025, available as both RSS and Soundixx-compatible JSON format
- Open source project, with source code available on GitHub
