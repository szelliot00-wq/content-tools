# Windows brings out the Rorschach test in everyone

Source: https://devblogs.microsoft.com/oldnewthing/20030825-00/?p=42803

## Summary
Raymond Chen's August 2003 post from "The Old New Thing" recounts how Windows packaging and UI elements became unintended Rorschach tests, with people projecting inappropriate or offensive imagery onto completely innocent designs. Microsoft repeatedly had to revise assets — a hologram, wallpapers, and UI icons — after governments and users complained about perceived nudity, political figures, or obscene shapes that the designers never intended.

## Key takeaways
- The Windows 95 anti-piracy hologram featured a shirtless infant; one government complained this constituted "naked children," forcing Microsoft to produce a replacement hologram with the baby in a shirt and overalls.
- The original "naked baby" hologram (without the shirt) is now a minor collector's item, since it was replaced quickly.
- Windows XP's default wallpaper "Red Moon Desert" was changed after users claimed it resembled buttocks; a user account icon was said to resemble Hitler; and another UI element was flagged as an obscene body part by a government.
- Chen's broader point is that ambiguous visual content — like clouds in a bitmap — naturally invites projection, and no matter how benign the intent, someone will find offense in it.
