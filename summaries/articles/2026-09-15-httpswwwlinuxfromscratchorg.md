# Linux from Scratch

Source: https://www.linuxfromscratch.org/

## Summary
Linux From Scratch (LFS) is a project that provides step-by-step instructions for building a custom Linux system entirely from source code. It is organized as a collection of subprojects, each extending the base system in different directions — from automation and multilib support to gaming and supplemental packages. The project also maintains community resources like hints, patches, and an editor's guide.

## Key takeaways
- **LFS (core book)** is the foundation: a guide to building a Linux system from source, from which all other subprojects derive.
- **BLFS** extends a finished LFS install into a more complete, usable system with additional software.
- **ALFS** provides automation tools for managing LFS and BLFS builds, reducing manual effort.
- **MLFS** adds multilib (32-bit binary) support to a standard LFS system.
- **GLFS** builds on BLFS/MLFS to support gaming software like Steam and Wine.
- **SLFS** offers supplemental packages beyond what BLFS covers.
- **Hints and Patches** are community resources for enhancements and fixes not covered in the main books.
- The project is entirely community-driven, with mailing lists, a wiki, mirrors, and contribution pathways.
