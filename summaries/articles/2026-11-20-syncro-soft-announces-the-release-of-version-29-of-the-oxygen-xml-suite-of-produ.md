# Syncro Soft Announces the Release of Version 29 of the Oxygen XML Suite of Products

Source: 

## Summary
Syncro Soft has released version 29 of the Oxygen XML suite, covering products including XML Editor, Web Author, PDF Chemistry, and others. The release focuses on three major areas: expanded S1000D support for aerospace and defense, enhanced AI capabilities through the Oxygen AI Positron 8.5 add-on, and improved DITA authoring tools including a new Content Reuse Finder. A free webinar showcasing the new features is scheduled for November 25, 2026.

## Key takeaways
- **S1000D support significantly expanded**: Full publication validation, BREX rule checking, dependency graphs, PDF/HTML preview for data modules, and bundled schemas for issues 5.0, 6, and 7.
- **AI capabilities deepened**: Oxygen AI Positron 8.5 can now explain document diffs, validate DITA maps, run transformations, resolve Git conflicts, and merge AI edits as tracked changes; third-party tools like Claude Code and Cursor can connect via MCP.
- **Content Reuse Finder**: New tool locates similar DITA content across a project to help teams identify and extract reusable components.
- **New DITA sample projects and templates**: Includes multi-product manuals, REST API guides, style guides, and a governance framework template.
- **Dark theme added**: The entire Oxygen interface now supports a dark color theme.
- **Improved file comparison**: Comparisons now open in editor tabs; directory comparison reports can be saved/loaded as XML.
- **Markdown enhancements**: Comments, Schematron validation, and a separate preview pane are now supported in Markdown documents.
- **Git Client updates**: Adds rebasing, AI-assisted conflict resolution, stashing selected files, and better multi-remote support.
- **Component updates**: Saxon 12.10, DITA-OT 4.4.1, XML Calabash 3.0.39, and JGit 7.7.1 are integrated.
