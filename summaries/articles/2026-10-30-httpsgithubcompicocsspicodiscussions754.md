# Pico CSS is no longer maintained

Source: https://github.com/picocss/pico/discussions/754

## Summary
Pico CSS, a minimal CSS framework for semantic HTML, has been officially discontinued. The maintainer (lucaslarroche) announced that v2.1.1 is the final release, and the GitHub repository was archived as read-only on October 4, 2026. The decision was driven by AI's growing ability to generate lightweight, accessible HTML with only the CSS it needs, reducing the value of a minimal CSS framework.

## Key takeaways
- **v2.1.1 is the last release** — no further updates, bug fixes, or new features will be made.
- **AI-generated CSS is cited as the reason** — tools that generate just the CSS needed per-component make a general-purpose minimal framework less relevant.
- **A modern rewrite would have been a different project** — the maintainer noted staying relevant would require rebuilding from scratch (OKLCH colors, cascade layers, Popover API, anchor positioning, native compiler), which was out of scope.
- **The project remains available** — existing versions are still accessible via npm, jsDelivr CDN, and picocss.com under the MIT license.
- **Community forks exist** — users who want continued development can look to community-maintained forks.
