# Show HN: My Terminal Themes Web App

Source: https://news.ycombinator.com/item?id=50098454

## Summary
A developer named "bado" posted on Hacker News announcing the launch of terminalthemes.com, a web app version of their long-maintained GitHub repo of terminal color schemes (iTerm2-Color-Schemes). After 15 years of planning, they built a full-featured site with over 800 themes, downloads for ~40 terminal formats, live previews, accessibility features, and community tools like voting, bookmarking, and theme submission. The post received positive community reception, with some users noting minor UI/UX feedback.

## Key takeaways
- The site hosts 800+ terminal themes with downloads for ~40 formats (iTerm, Ghostty, Windows Terminal, and more)
- No account required to browse or download; free registration unlocks voting, bookmarking, and theme submission
- Live terminal and code previews offer a more realistic look than the static ANSI screenshots on the GitHub repo
- Accessibility (a11y) features and a "Find My Theme" discovery tool were explicitly prioritized
- Past GitHub contributors can claim authorship of their themes by registering and using the "Claim Authorship" button
- Community feedback flagged that theme previews are too small on mobile, and the "remember" format button has a bug when switching away from the default iTerm selection
