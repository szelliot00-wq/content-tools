# Lemmings CSS Animation

Source: https://markblah.github.io/lemmings/

## Summary
"Lemmings CSS Animation" is a GitHub project by MarkBlah that recreates the classic Lemmings game behavior using pure CSS animations. It provides an interactive playground where users can add walker characters that navigate various terrain types. The project demonstrates CSS animation capabilities through several demo scenarios showing how walkers interact with different obstacles and environments.

## Key takeaways
- The project is a CSS-only animation experiment inspired by the classic Lemmings video game, hosted on GitHub with 29 stars and 1 fork.
- An interactive "Walker playground" lets users dynamically add walker characters via a button.
- Multiple terrain scenarios are demonstrated: stairs (climbable and too-tall-to-climb), floating platforms, pits, walls, cards with interactive UI elements, a cage, and a reading section.
- The "stairs too tall to climb" and "cage" scenarios suggest the walkers have physics/collision logic encoded in CSS to handle edge cases and boundaries.
- The project doubles as a showcase for how CSS animations can interact with real DOM elements like buttons, inputs, and cards.
