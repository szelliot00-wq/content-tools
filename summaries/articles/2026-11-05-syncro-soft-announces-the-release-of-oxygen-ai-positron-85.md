# Syncro Soft Announces the Release of Oxygen AI Positron 8.5

Source: 

## Summary
Syncro Soft has released Oxygen AI Positron 8.5, an update to its AI assistant plugins for the Oxygen XML suite. The release focuses on multi-agent task delegation, improved conversation management, and expanded team controls over AI providers. It also adds new AI models from OpenAI, Anthropic, and xAI, along with new tools for documentation workflows like document comparison and batch conversion.

## Key takeaways
- **Sub-agent support**: Agents can now delegate focused tasks to sub-agents, with real-time progress visibility and user approval required for tool calls.
- **Dedicated AI window and chat history**: The assistant can open in a separate window; chat history is searchable, pinnable, exportable, and auto-cleans inactive conversations.
- **Team-level model governance**: Team owners can control which AI providers and models are available to their teams, and block specific models while retaining full access themselves.
- **Expanded model support**: Adds OpenAI GPT-6.x variants, Anthropic Sonnet 5.5/Haiku 5.5 (including Thinking variants), and xAI Grok 4.7.
- **New documentation tools**: AI can now compare document versions, reply to review comments, read profiling conditions, and perform batch format conversions.
- **Smarter memory**: The AI updates existing stored preferences instead of creating conflicting duplicate rules.
- **MCP Server improvements**: The Oxygen MCP Server now shows live status, enforces consistent tool-use restrictions for external agents (e.g. Claude Code, GitHub Copilot), and can restore its running state on app launch.
