# llama.cpp

Source: https://llama.app

## Summary
llama.cpp is an open-source, locally-run AI platform that runs entirely on your computer, emphasizing privacy and offline availability. It supports a range of modern open-weight models and is optimized to run across various hardware configurations. The project has over 123,500 GitHub stars, indicating strong community adoption.

## Key takeaways
- llama.cpp runs AI models locally on your machine — no cloud, no data leaving your device.
- It supports pairing with a local coding agent for developer workflows.
- It is hardware-agnostic, optimized to run on a wide range of devices.
- Featured models include Qwen 3.6 (vision/reasoning), Gemma 4 (multimodal, 140+ languages), GPT-OSS (OpenAI's first open-weight model since GPT-2), and Gemma 3 (128K context, edge-to-cloud).
- Available via Mac download, CLI install, Homebrew, Winget, or building from source.
