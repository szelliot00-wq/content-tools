# Wasmer (YC S19) Is Hiring OS/Hypervisor Experts in Europe

Source: https://www.workatastartup.com/jobs/98722

## Summary
Wasmer (YC S19) is hiring a Senior Operating Systems / Hypervisor Engineer to work on WASIX — an OS emulation layer that brings full POSIX semantics (threads, processes, sockets, signals, etc.) to WebAssembly. The role is fully remote within CET ±2 hours, requires 3+ years of experience, and does not require US citizenship or a visa. Wasmer's broader mission is to make WebAssembly a universal runtime for server-side code across local, cloud, and edge environments.

## Key takeaways
- **Role:** Senior OS/Hypervisor Engineer building POSIX emulation on top of WebAssembly (WASIX project)
- **Stack:** Rust and Embedded Linux are the core technologies
- **Location:** Fully remote, but candidates must be within CET ±2 timezone (effectively Europe and nearby regions)
- **Ideal candidate:** Someone with deep knowledge of OS internals — processes, signals, file descriptors, memory management — who can drive work from design to shipped code
- **Company mission:** Wasmer aims to do for server-side WebAssembly what Node.js did for server-side JavaScript, supporting C/C++, Rust, Go, Python, and more
- **Application process:** Applicants should send an email with subject "Why I'm awesome" listing 3 significant personal or technical achievements, emphasizing communication and high agency
- **Culture:** Values self-direction ("High-Agency") and a builder mindset ("Be a Maker")
