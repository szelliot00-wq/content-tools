# Syncro Soft Announces the Release of Oxygen AI Positron 8.4

Source: 

## Summary
Syncro Soft has released Oxygen AI Positron 8.4, a major update to its AI plugin suite for the Oxygen XML product family. The headline feature is local MCP (Model Context Protocol) server support, enabling third-party AI tools like Claude Desktop, Claude Code, and Cursor to connect directly to Oxygen and use its AI tools. The release also improves AI-assisted editing workflows, expands supported AI models across multiple providers, and introduces new validation and transformation automation tools.

## Key takeaways
- **MCP server integration**: AI Positron can now run as a local MCP HTTP server, letting external AI assistants (Claude, Cursor, etc.) connect to Oxygen, access open documents and project context, and make file changes that users can accept, modify, or reject.
- **Improved AI editing**: AI-generated changes are now merged into documents rather than overwriting them; if Track Changes is enabled, AI edits are tracked for easy review. The AI can also ask clarifying questions before making edits.
- **Smarter Rewrite/Translate actions**: These now apply targeted edits instead of regenerating full documents, reducing token usage and better preserving markup in large files.
- **Expanded model support**: New models added include Claude Sonnet 5 and Opus 5 (Anthropic), GPT-5.6 variants (OpenAI), Gemini 3.5–3.8 Flash (Google), and Grok 4.3–4.6 (xAI for Enterprise).
- **New validation tools**: `validate_and_check_for_completeness` and `validate_with_schematron` allow AI-driven document validation during chat; new transformation scenario tools automate publishing and testing (requires Oxygen XML 29+).
- **UX improvements**: Markdown responses now render in rich preview, folders can be attached to chat messages, and AI actions can be organized into sub-categories.
- **Free webinar**: A hands-on webinar covering the new features is scheduled for October 21, 2026.
