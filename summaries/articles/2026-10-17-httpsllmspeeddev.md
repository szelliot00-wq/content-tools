# Show HN: Llmspeed – feel how fast a local LLM runs before you buy the hardware

Source: https://llmspeed.dev/

## Summary
Llmspeed is an open-source web tool that lets you simulate how fast a local LLM will feel on specific hardware before you purchase it. You can select a hardware configuration (GPU, Mac, CPU-only, or cloud), a model, and a quantization level, then watch a real-time typing simulation at the expected tokens-per-second rate. It supports side-by-side "race" comparisons between configurations and covers a wide range of consumer, prosumer, and cloud hardware.

## Key takeaways
- Simulates perceived LLM output speed (tokens/sec) so you can feel the difference between hardware choices before buying.
- Covers a broad hardware catalog: NVIDIA RTX 3060–5090, AMD GPUs, Apple Silicon (M2–M5), Intel Arc, and cloud options (H100, A100, H200).
- Supports popular models including Llama 3.1 8B, Qwen 3.x, DeepSeek R1, Gemma 4, and others, with quantization options like Q4_K_M.
- Lets you race multiple hardware/model configurations side by side for direct comparison.
- Open source on GitHub, with transparent methodology ("How we calculated this" section).
