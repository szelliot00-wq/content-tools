# Zero-Mem: Zero-Token Memory Operations for LLM Agents

Source: https://arxiv.org/abs/2607.29377

## Summary
Zero-Mem is a memory system for LLM agents that eliminates LLM calls during memory operations entirely — no tokens are consumed until the final question-answering step. It stores raw interaction traces organized in two structures: an entity-context graph (for cross-interaction relationships) and a temporal hierarchy (for conversational locality). Retrieval and evidence filtering are handled deterministically, with only the final reader invoking an LLM. On long-memory and long-context QA benchmarks, Zero-Mem matches competitive baselines while cutting memory-operation time by 57.6% versus the fastest prior approach.

## Key takeaways
- **Zero token overhead for memory**: All memory operations (storage, indexing, retrieval, conflict resolution) are performed without LLM calls — only encoder computation is used, which is accounted for separately.
- **Dual-structure storage**: Traces are indexed in two complementary ways — an entity-context graph for relational/cross-session connections, and a temporal hierarchy for session-local context.
- **Deterministic calibration**: Conflicting evidence is discarded algorithmically, keeping the final reader grounded in retrieved source traces rather than generated summaries.
- **Preserves original traces**: Unlike systems that summarize or merge past interactions, Zero-Mem keeps the raw interaction record, avoiding lossy compression.
- **Significant efficiency gains**: 57.6% reduction in memory-operation latency relative to the fastest compared baseline, with competitive QA accuracy.
- **Challenges the assumption that memory needs generation**: The core finding is that structured agent memory does not require generating intermediate representations of past interactions.
