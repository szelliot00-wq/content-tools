# Webinar: Beyond the Chatbot: Harnessing Agentic AI, MCP, and Validation Tools with Oxygen AI Positron

Source: 

## Summary
This article announces a free webinar on October 21 hosted by Syncro Soft, focused on how AI in technical documentation is advancing beyond basic chatbots. Sorin Carbunaru will demonstrate agentic workflows in Oxygen AI Positron, showing how tools like Model Context Protocol (MCP) integrations and validation tools enable multi-step, intelligent operations while keeping users in control.

## Key takeaways
- The webinar covers agentic AI workflows in Oxygen AI Positron, going beyond simple text generation to multi-step, planned operations.
- Model Context Protocol (MCP) integrations are highlighted as a key component enabling intelligent, connected workflows.
- Validation tools are built into the workflow to keep documentation projects valid throughout AI-assisted editing.
- The session is free but requires registration; it takes place on October 21.
- The presenter is Sorin Carbunaru, Senior Software Developer at Syncro Soft, the company behind OxygenXML.
