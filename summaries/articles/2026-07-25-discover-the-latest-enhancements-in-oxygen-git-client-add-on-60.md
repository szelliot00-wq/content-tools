# Discover the Latest Enhancements in Oxygen Git Client Add-on 6.0!

Source: 

## Summary
Syncro Soft has released Oxygen Git Client Add-on 6.0, a major update to its Git integration for Oxygen XML Editor, XML Author, XML Developer, and JSON Editor. The release focuses on improving workflow clarity, conflict resolution, and everyday Git operations. Notable additions include a redesigned History view, AI-assisted merge conflict resolution via AI Positron, and several quality-of-life improvements for managing credentials, stashing, and rebasing.

## Key takeaways
- **Redesigned Git History view** — uncommitted changes appear as pending commits in the graph, active operations (merge, rebase, cherry-pick, revert) are visually marked, and any two revisions (including working copy) can be compared directly.
- **AI-assisted conflict resolution** — AI Positron proposes merge conflict resolutions with explanations; users retain full control and must approve changes before they are applied.
- **Better interrupted workflow recovery** — context-sensitive controls let users safely continue, restart, or abort interrupted merge, rebase, cherry-pick, and revert operations.
- **Improved credential management** — a new Credentials preferences page lets users review and remove stored credentials individually, with reduced repeated authentication prompts.
- **Partial stashing** — users can stash only selected files rather than the entire working copy, giving finer control over in-progress changes.
- **Visual image diffs** — image changes are shown as true side-by-side comparisons, making asset and design reviews easier.
- **Workflow additions** — new Push/Pull actions on the current branch menu, faster remote branch discovery, improved Blame integration, and customizable AI instructions for commit messages.
