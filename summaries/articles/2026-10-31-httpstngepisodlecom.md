# Show HN: To Honor Sir Patrick Stewart, Enjoy the TNG Episode Guessing Game

Source: https://tng.episodle.com/

## Summary
TNG.EPISODLE is a daily web-based guessing game inspired by Wordle, built around Star Trek: The Next Generation episodes. Players are shown episode images as clues and must identify the correct episode title from a searchable list. The game was created as a tribute to Sir Patrick Stewart, who played Captain Jean-Luc Picard in TNG.

## Key takeaways
- The game uses TNG episode images as visual clues to identify episodes.
- Players search for episode titles, select one, and submit a guess, with a limited number of guesses remaining per round.
- A skip option is available if players are stuck on a clue.
- The game is numbered sequentially (currently on game 304), suggesting it runs as a daily puzzle like Wordle.
- It includes an about section, statistics tracking, and a how-to-play guide for new players.
- The site uses Google's privacy/cookie policy, indicating Google services are in use.
