# The EASIEST Way to Make AI Micro Dramas (Starring You)

Video ID: `5t_J_MVT7nM`

## Summary
This video is a practical tutorial on creating AI-generated micro-dramas — short, scripted video narratives — using a tool called Higsfield's short drama feature. The host demonstrates two workflows: a manual step-by-step approach inside Higsfield's UI, and a more automated approach using Claude (via a Higsfield plugin) to handle scripting and generation conversationally. The video is aimed at content creators, brands, and social media marketers who want to produce high-quality, personalized video content without any acting or filming. The host inserts themselves as a character in both demos to show how personal branding and likeness can be embedded into AI-generated stories.

## Key insights
- AI micro-dramas are a growing content format being used for social media virality, brand advertising, and YouTube series — with no filming or acting required from the creator.
- Higsfield's short drama tool is the primary platform used; it analyzes uploaded scripts and extracts characters, locations, and props automatically.
- Scripts must follow a specific structure: scene directions, character names in ALL CAPS with ages noted, dialogue attribution, shot type (e.g., interior/exterior), and time of day.
- To insert yourself as a character, you upload a photo of your face; Higsfield then generates a multi-angle "character sheet" so your likeness can be rendered consistently across scenes.
- The tool supports multiple visual styles including anime, K-drama, and others (the host chose K-drama for the second demo).
- Assets (locations, props, character faces) can be individually edited using an in-tool chat/agent interface — for example, the host used a real Ferrari pit wall photo as a reference image to improve a generated location.
- Video can be generated at different resolutions: 480p draft (~cheaper, for review) or 720p (higher quality, more credits). Upscaling is available after initial generation.
- The Ultra plan costs ~3,000 credits/month; the F1 drama cost ~300–400 credits, the office drama cost ~226 credits. A Black Friday deal offering ~65% off was available at time of filming.
- The Claude desktop app integration allows fully conversational workflow: prompt Claude to write the script, adjust details mid-conversation (rename characters, change accents, condense length), upload your photo when prompted, and generate the video — all within one chat.
- The Claude plugin approach supports a spectrum from full automation (one-click generation) to granular step-by-step control, making it flexible for both volume creators and perfectionists.
- A key limitation noted: when a character wears a helmet or obscures their face, the likeness insertion is less impactful — worth planning for in the script.
- Multiple episodes with shared characters, locations, and storylines can be built as a series within the same Higsfield project.

## Patterns & frameworks

**Two-Workflow Pattern (Manual vs. Automated)**
The video presents two distinct creation paths for the same output:
1. *Manual (Higsfield UI)*: Upload script → analyze → review/edit each asset individually → generate episode. Gives maximum control but takes more time (~15 min, ~300–400 credits).
2. *Automated (Claude + Higsfield Plugin)*: Converse with Claude to write the script, adjust it iteratively, upload a photo when prompted, and let the pipeline handle asset generation and editing. Faster iteration, less hands-on asset review (~15 min, ~226 credits).

**Script Structure Formula**
Every scene needs: scene direction + shot type (INT/EXT, day/night, close-up etc.) + character name in CAPS + age + dialogue. This structured format allows Higsfield to automatically parse characters, locations, and props.

**Asset Refinement Loop**
For any generated asset (location, prop, character), the tool provides an inline chat/agent where you can describe changes and attach reference images. This iterative edit loop lets creators fine-tune visuals to match brand colors, real-world references, or specific aesthetic requirements without starting over.

**Likeness Insertion via Character Sheet**
Upload one face photo → generate a multi-angle character sheet → the tool uses it to maintain visual consistency of that person across all shots in the drama. This is the core mechanism for personalizing AI video with a real person's appearance.
