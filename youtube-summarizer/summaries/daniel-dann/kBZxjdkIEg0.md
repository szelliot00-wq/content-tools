# Haiku AI Review (2026) AI That Turns Workflows Into Step-by-Step Guides

Video ID: `kBZxjdkIEg0`

## Summary
This video is a sponsored review of Haiku, a workflow documentation platform that automatically converts recorded work sessions into structured, step-by-step guides. The presenter, Daniel, demonstrates how the browser extension captures actions in real time so teams avoid the overhead of writing instructions after the fact. The core argument is that documentation bottlenecks disappear when capture happens during the task rather than after it. It is most relevant to team leads, operations managers, HR professionals, and anyone responsible for creating onboarding or training materials.

## Key insights
- Haiku records workflows passively via a browser extension — no need to pause, take screenshots, or write steps afterward.
- The output is not a raw screen recording; it is a polished, editable guide with screenshots, click markers, and auto-generated descriptions already included.
- A free plan is available with up to 10 guides and requires no credit card, lowering the barrier to try the tool.
- Audio and webcam recording can be layered on top of the screen capture for steps that benefit from verbal or visual context.
- Built-in AI editing can rewrite step descriptions automatically, reducing manual cleanup time significantly.
- Sensitive information can be blurred directly within the editor before sharing.
- Finished guides can be shared via link, embedded in other platforms, or exported in multiple formats — giving flexibility in how teams distribute documentation.
- All guides live in a single shared workspace, replacing scattered folders and outdated documents.
- Analytics track views and completion progress per guide, letting teams identify which materials are actively used and which need updating.
- Guides can be updated in place when workflows change, rather than rebuilt from scratch.
- The platform supports both browser and desktop task capture, making it applicable beyond web-only workflows.

## Use cases
- **Onboarding new employees** — create reusable walk-throughs for common internal tools and processes without a trainer having to repeat themselves.
- **Customer tutorials** — build product guides that show exactly how to complete tasks inside a tool, with screenshots and click markers already embedded.
- **Standard operating procedures (SOPs)** — replace static Word or PDF docs with living guides that can be updated whenever the process changes.
- **Internal knowledge management** — centralize institutional knowledge so it doesn't live only in one person's head or scattered across folders.
- **Remote or async teams** — share process documentation across time zones without scheduling a screen-share session.
- **Customer success and support teams** — quickly produce how-to guides for frequently asked questions or common support tickets.
- **Small teams without dedicated technical writers** — capture expertise from subject-matter experts without requiring them to write documentation manually.

## Patterns & frameworks
- **Capture-then-publish workflow**: The core pattern is completing a task exactly as you normally would while the tool records in the background, then reviewing and publishing the auto-generated guide. This inverts the traditional document-first approach (write instructions, then do the task) into a do-first, document-automatically flow.
- **Progressive enrichment**: The raw capture serves as a baseline that can be layered with additional context — AI-improved descriptions, audio narration, webcam footage, blurred sensitive fields, and custom branding — in a non-destructive editing step after recording.
- **Living documentation**: Rather than treating a guide as a finished artifact, Haiku treats it as an updatable asset. When a process changes, the guide is edited in place, preserving the existing link and embed while keeping content current. This avoids documentation rot.
- **Analytics-driven maintenance loop**: Built-in view and completion tracking closes the feedback loop — teams can see which guides are actually used, then prioritize updates or improvements on the ones that matter most rather than guessing.
