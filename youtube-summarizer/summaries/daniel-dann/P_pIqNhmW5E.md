## Patterns & frameworks

**Persistent Project Context**
All files, conversations, and outputs live inside a named project. Every new task inherits the full context of prior tasks automatically, so work is cumulative rather than episodic. This is the foundational pattern the entire workflow depends on.

**Upload Once, Use Everywhere**
Resources (analytics data, brand guidelines, previous scripts) are uploaded at the start of a project and remain available to every subsequent AI call. Eliminates repeated file handling and ensures consistency across tasks.

**Multi-Model Comparison Loop**
Run the same prompt through two different models (Claude Opus → GPT 5.6) inside the same project, view responses side by side, and synthesize the best elements from each. Useful for creative tasks where a single model's framing may be limiting.

**Data → Insight → Deliverable Pipeline**
A three-stage sequential workflow: (1) analyze real performance data to surface patterns, (2) use those patterns to generate structured strategic options, (3) convert the chosen option into a finished, downloadable artifact (outline, PPTX, thumbnail). Each stage feeds the next.

**In-Place Iteration**
Rather than restarting a conversation to revise a document, edits are requested within the same thread and the document updates in place. Prior versions remain accessible, functioning like lightweight version control inside the chat.
