This is a sponsored review of eM Client, a privacy-focused email client for Windows, macOS, iOS, and Android. The reviewer (Daniel) tests its AI writing assistant against a real overflowing inbox rather than curated demos, covering drafting, editing, translating, and replying to emails. ## Key insights
- **30-day free trial** covers the full unlimited version with no cost commitment; after trial, users choose the free tier or a paid plan
- **AI drafting from scratch**: paste rough meeting notes, choose length, language, and tone, and the assistant generates a sendable draft
- **Reply with AI** offers contextual options: simple thank-you, polite decline, or redirect to a colleague — all from within the reply workflow
- **AI editing**: select existing draft text and apply "shorten" or tone adjustments without rewriting manually
- **Built-in translation**: works both ways — translate incoming messages while reading, or outgoing messages before sending, without leaving the app
- **Privacy architecture**: AI features only send data when the user explicitly triggers them (e.g., clicking "Reply with AI"); data is never stored, logged, or used to train models
- **Tracking pixel blocking**: detects and blocks read-receipt pixels in incoming mail, preventing silent open-tracking by senders
- **Profiles**: separate email environments for personal and professional accounts on the same device, each with independent settings
- **Quick text**: save reusable text snippets and insert them instantly to avoid repetitive typing
- **Quick actions**: chain multiple tasks (tag + move to folder + mark as read) into a single one-click command — normally three separate actions
- **Keyboard shortcuts** (quick move, quick copy): reduce mouse dependency when processing high volumes of messages
- **Unified inbox ("All Inboxes")**: consolidates multiple accounts into one view
- **Smaller productivity tools**: undo send, send later, email notes, attachments view
- **Pricing split**: Personal license (unlimited accounts, up to 3 devices) targets freelancers; Business license adds team management and a license manager for organizations
- **Payment options**: subscription includes AI features; one-time payment license can add AI via a separate add-on
- **20% discount code** valid for 6 weeks on new licenses, mentioned in video description

## Patterns & frameworks

**Explicit-action-only AI data model**
Data is only sent to the AI provider when the user deliberately triggers a feature. Nothing is transmitted passively, nothing is stored server-side, and nothing feeds model training. The framework is: user action → one-time send → no retention.

**Chained task automation via Quick Actions**
A repeatable pattern where multiple discrete email-processing steps (tag, move, mark read) are bundled into a single named command. The mental model is: identify your most common multi-step sequences → define them once → execute with one click.

**In-workflow translation**
Rather than context-switching to an external tool, translation is embedded at both the read and compose stages. The pattern keeps the user inside a single workflow for the entire message lifecycle — receive → read (translate if needed) → compose → translate outgoing → send.

**Tiered licensing with optional AI add-on**
A pricing pattern that separates core functionality from AI features, allowing one-time-payment buyers to bolt on AI separately rather than forcing a subscription for all users. This gives buyers flexibility based on their AI usage needs.
