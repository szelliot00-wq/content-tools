# Mina AI Review (2026) I Let an AI Teammate Run My Live Zoom Call

Video ID: `TtZBENIsJTE`

## Summary
This video reviews Mina, an AI-powered meeting assistant positioned as an "agentic teammate" rather than a passive recorder. The core argument is that traditional meeting tools only add value after a call ends, while Mina participates during live conversations and then carries that context into post-meeting workflows. Daniel (the reviewer) demonstrates Mina by running it through an actual Zoom business review call, showing both real-time interaction and post-meeting capabilities. The video is most relevant to team leads, project managers, and knowledge workers whose meetings regularly generate significant follow-up work.

## Key insights
- **Real-time participation vs. passive recording**: Unlike tools that only summarize after the fact, Mina can respond to questions mid-call — e.g., surfacing action items or key points while the discussion is still live.
- **Calendar integration as a prerequisite**: Connecting your calendar is required to unlock Mina's pre-meeting context features, which include reminders and background on upcoming calls before they start.
- **Onboarding tailored to role**: Mina asks role-specific questions during setup so the workspace is contextually relevant from day one rather than a blank slate.
- **Structured summaries, not raw transcripts**: Post-meeting, Mina generates a cleaned-up recap (decisions, action items, key points) rather than dumping a wall of transcript text.
- **Gmail integration for follow-up distribution**: Mina can send the meeting recap directly via Gmail, so outcomes aren't siloed inside the platform.
- **200+ workflow integrations**: Mina connects to Jira, Notion, Salesforce, and many other tools, allowing it to push meeting context into CRMs, project management systems, docs, and communication channels.
- **"Skills" as action layer**: Skills are the specific actions Mina can take with collected meeting context — turning conversation data into usable outputs for the team.
- **Memory across sessions**: Mina retains context from past meetings, so team members can query it later if they forget a detail discussed previously.
- **Visible AI presence on calls**: When Mina joins a Zoom call, it is visible to all participants — it's not hidden in the background, which signals transparency about AI involvement.

## Patterns & frameworks

**Agentic Teammate Model**
The central framework positioning Mina: an AI that is active before, during, and after a meeting rather than only useful in one phase. The three-phase loop is: (1) pre-meeting context and reminders via calendar integration, (2) real-time participation and response during the live call, (3) post-meeting structured output and workflow distribution.

**Skills + Integrations Two-Layer Architecture**
Mina separates *what it can do* (Skills — the actions it takes on meeting context) from *where results go* (Integrations — the external tools it connects to). This decoupling means the same meeting output can be routed to different destinations depending on which integrations are active.

**Context Continuity Loop**
Rather than treating each meeting as isolated, Mina maintains memory across sessions. This creates a continuity loop where past meeting context remains queryable, reducing information loss between calls and enabling better follow-up in future meetings.
