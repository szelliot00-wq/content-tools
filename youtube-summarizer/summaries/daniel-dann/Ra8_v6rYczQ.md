## Key insights
- **Static vs. dynamic QR codes**: Static codes point to a fixed destination forever; dynamic codes let you change the destination URL after the code is printed, without reprinting anything.
- **The core value proposition**: If you've spent hundreds or thousands of dollars on physical ad boards, dynamic QR codes let you reuse those materials across multiple campaigns simply by updating the URL in a dashboard.
- **QR Tiger workflow**: Paste a URL → choose dynamic type → generate → customize → download → deploy.
- **Customization options in QR Tiger**: You can change the dot/pixel pattern, the outer shape, add a brand logo, adjust colors, add a frame, and write a call-to-action text — moving beyond the default black-and-white look.
- **Testing before deployment**: The video emphasizes scanning the code with a phone camera before putting it on physical materials to confirm it routes correctly.

- **Built-in analytics**: QR Tiger provides a tracking dashboard showing total scan counts, top geographic locations, and engagement stats, giving marketers insight into how and where customers are interacting with the code.
- **Campaign flexibility example**: "Daniel's Menswear" used one poster first for a weekly sale, then redirected it to social media — zero reprinting required.

## Patterns & frameworks

**Static vs. Dynamic QR Decision Framework**
A simple fork: if the destination will never change, use static (simpler, no account needed). If the destination may change — for campaigns, seasonal promotions, or evolving content — always use dynamic. The key question is: *will I need to update this after it's printed?*

**Create → Customize → Test → Deploy → Update loop**
The repeatable workflow shown in the video:
1. **Create** — paste URL, select dynamic type, generate code.
2. **Customize** — apply brand colors, logo, pattern, frame, and call-to-action.
3. **Test** — scan with a phone before any physical printing to confirm correct routing.
4. **Deploy** — print and place on physical materials.
5. **Update** — edit the destination URL in the dashboard when campaigns change; the physical code requires no changes.

**"Same Code, New Campaign" mental model**
Treat the printed QR code as permanent infrastructure, not campaign-specific collateral. The physical artifact is reusable; the digital destination is the variable. This reframes QR codes from a one-use print asset into a long-lived, flexible channel.
