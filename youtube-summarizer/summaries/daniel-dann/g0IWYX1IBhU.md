- **Two hidden costs most people miss**: A domain (the site's name) and hosting (where it lives) are typically billed separately and annually — Weblium bundles both into one subscription.
- **Core mental model**: A site is made of blocks; blocks are made of elements. Standard blocks use a column grid (add/split/resize columns). Once you internalize this, the entire editor makes sense.
- **Global blocks** save significant time: making the header a global block means editing it once updates it across every page automatically.
- **Flex Block** is Weblium's key differentiator vs. standard no-code builders: it provides a free-form canvas with no columns or containers, allowing elements to be dragged anywhere — similar to a design tool like Figma. ## Patterns & frameworks

**Block + Element mental model**
Every page is composed of blocks stacked vertically; every block contains elements (text, images, buttons, etc.). Standard blocks use a column grid — you add, split, and resize columns. This is the foundational logic of the entire editor; learning it once unlocks all other features.

**Standard Grid vs. Flex Block**
A two-tier layout system. Standard blocks constrain elements to columns (fast, structured, but templated-looking). Flex Block provides a free-form canvas where elements can be placed anywhere with drag-and-drop, overlapped using layers, and snapped via alignment guides — at the cost of requiring manual responsive adjustments per screen size (desktop → tablet → mobile).

**Global Blocks pattern**
Designate repeated UI sections (e.g., header, footer) as "global blocks." A single edit propagates to every page automatically, eliminating repetitive updates across a multi-page site.

**Pre-build asset checklist**
Before touching the builder: collect copy, photos, logo, inspiration examples, testimonials, and a page map. This is a recommended workflow step to reduce friction and decision fatigue during the actual build.

**AI-assisted content scaffolding**
Use the built-in AI (Evo AI) at two stages: (1) planning the page structure before building, and (2) generating specific blocks or copy on demand mid-build. Treats the AI as a collaborator embedded in the workflow, not a separate tool.

**Bundled cost model**
Frame the total cost of a website as domain + hosting + builder. Weblium collapses all three into one subscription, making the pricing comparison against agencies ($2,000+) or freelancers more favorable when total cost of ownership is considered.
