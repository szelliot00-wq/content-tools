## Patterns & frameworks
**Tiered plan selection** — Saily structures data plans across four named categories (Country, Regional, Ultra, Cruise) so users self-select based on trip type rather than navigating a flat list. Each category addresses a distinct travel scenario, reducing decision fatigue.

**Add-on model** — The phone number is positioned as an optional layer on top of the core data eSIM rather than a separate product. This keeps onboarding simple (data-only users aren't forced through extra steps) while expanding the service's value for users who need it.

**Pre-purchase review screen** — Before any transaction is confirmed, the app consolidates plan details, final price, discount codes, and activation deadline onto a single summary screen. This pattern reduces buyer uncertainty and gives a natural checkpoint before committing.

**Automatic activation on arrival** — Rather than requiring manual setup at the destination, the eSIM activates when the device detects the supported local network. This removes a common friction point for less technical travelers.
