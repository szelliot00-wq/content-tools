- The creation flow starts with a **prompt**, not a blank slide. Users describe their topic and the AI generates a full draft.
- Before the full deck is built, Gamma first generates an **outline** so the user can review and adjust the structure before committing to the full generation.
- Key pre-generation settings include: number of cards/slides, editing mode (classic was chosen for full control), output format, and language.

- Every element is also **fully manually editable** — text, images, and layout can be clicked and changed just like in traditional presentation software.
- A large library of **built-in themes** allows a complete visual overhaul in one click without touching the content.

## Patterns & frameworks

**Prompt → Outline → Generate → Refine loop**
Gamma's core workflow is a four-stage process: (1) describe your topic via a prompt, (2) review and edit an AI-generated outline, (3) generate the full deck, (4) iterate using natural language AI instructions or manual edits. The outline stage is a notable checkpoint that prevents wasted generation — you validate structure before committing.

**AI-first, manual-always fallback**
The platform's design philosophy keeps the user in control at every stage. AI handles the heavy lifting (structure, design, imagery), but every element remains manually editable. This means AI serves as a starting accelerator, not a locked-in generator.

**Global vs. granular editing**
Gamma distinguishes between two levels of editing: (a) global changes via natural language commands (e.g., restyle the entire deck) that propagate across all slides, and (b) granular per-element edits for individual images or text blocks. This two-level model lets users work efficiently at scale while still fine-tuning details.
